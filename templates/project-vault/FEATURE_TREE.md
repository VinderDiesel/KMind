## 维护约定（强制）

1. **初始化**：`kmind init --project` 会确保本文件存在；团队内容写在下方分区，勿删本约定区块。
2. **盘点**：整理某系统前，先按模块/阶段/配置/踩坑补全表格行（可暂不 capture）。
3. **入库后**：对应行改 `done` 并写上资产 id；一卡一事，禁止 Skills / 工具安装说明进库。
4. **对照补缺**：`kmind_coverage` 之外，用本表扫 `todo` 行；人工功能问答题答不出 → 不得宣称完整。
5. **进 git**：与 `knowledge/` 一并提交；勿提交 `raw/`、`index.db`。
